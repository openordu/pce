``` tab [group1:Info]
::: magazinestyle
Cú is an Irish name with two records. One bearer is a son whom Cáinte fathered, brother to Cian and Cethe. A second sense belongs to the word itself. The Irish cú means hound, and it opens the names of a number of early figures. Some names split the word from the rest. Others fuse it, as in the name of the hero Cúchulainn. The dictionary alphabetizes all of these letter by letter, whatever the spacing. Readers meet the prefix again in the tale of how Sétanta took the hound name of the smith Culann.

:::
```
