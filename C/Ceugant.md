``` tab [group1:Info]
::: magazinestyle
Ceugant marks the outermost ring of a Welsh cosmogony drawn as concentric circles. Llewelyn Sion set out this scheme in the sixteenth century. Beyond every created order sits Ceugant, the last circle. Infinity alone dwells there. The Welsh word carries the senses sure, true, and infinity, and some writers spell the name Ceugand.

:::
```
