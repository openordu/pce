``` tab [group1:Info]
::: magazinestyle
Caipre is another way to spell the name Cairbre.
The old Irish stories use both forms.
They refer to the very same men.
A scribe might write Caipre where another writes Cairbre.
The name marks poets, kings, and warriors alike.
Many figures in the legends bore it.
Some readers meet the longer form Cairpre as well.
Each spelling points to the same families of heroes.
So Caipre works as a simple variant, not a separate person.
It names the same men whose deeds fill the ancient tales.

:::
```
