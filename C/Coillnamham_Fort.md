``` tab [group1:Info]
::: magazinestyle
Coillnamham Fort is a name for Dún Aonghusa in the Aran Isles. The name compares with Irish coill, wood or forest, and namae, enemy. Liam O'Flaherty, the Anglo-Irish writer who lived from 1896 to 1984, uses this name. Other Anglo-Irish writers use it as well.

:::
```
