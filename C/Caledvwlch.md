::: magazinestyle
Caledvwlch is a variant spelling of the name Caledfwlch. Caledfwlch is the Welsh name for the great sword of Arthur. The same blade travels across many traditions. Irish legend calls it Caladbolg. Later English romance knows the sword as Excalibur. Arthur carries this blade into battle. See the entry for Caledfwlch for the fuller account. This spelling merely offers an alternate form.

:::
