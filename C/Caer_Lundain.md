``` tab [group1:Info]
::: magazinestyle
Caer Lundain is a variant spelling of the newer Welsh name for London. The fuller form is Caer Llundain, and the pair Lundein stands beside it. All these words name the same English capital. More recent Welsh speech gave London this fresh title. The older name Caer Lludd stayed in memory all the while. So Caer Lundain and Caer Llundain meet at one city. The capital keeps a Welsh voice in both forms.

:::
```
